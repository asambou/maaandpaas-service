# Maa & Paa's Homecare Service — Website

Static website for Maa & Paa's Homecare Service (Sanchaba Sulay Jobe, The Gambia). Comfort. Care. Companionship.

## Structure
- `index.html`, `about.html`, `services.html`, `contact.html` — pages
- `css/style.css` — shared styles
- `js/main.js` — mobile nav + contact form
- `js/footer.js` — injects the shared footer
- `assets/logo.svg` — logo mark

## Local preview
Open `index.html` in a browser, or run a local server:
```
python3 -m http.server 8000
```
then visit `http://localhost:8000`.

## Deploy
Deployed via Cloudflare Pages. See `launch-guide.md` for domain, hosting, and social account setup steps.
